Log-scaled y-axis

Point and line tracks take y_scale='log' to draw their y-axis on a base-10 log scale, ticked at powers of ten. This is set per track, so log and linear tracks can sit in the same viewer. Rows with values ≤ 0 have no position on a log axis; they are dropped with a warning. A y_range is given in data units, e.g. y_range=(1e-8, 1), and tooltips show data values.

When zoomed out, values in a bin are first aggregated (aggregate='mean', 'sum' or 'max') and the result is then placed on the log axis, so 'mean' is the ordinary arithmetic mean.

qdf['pval'] = 10 ** -np.random.default_rng(1).exponential(1.5, len(qdf))

viewer_log = (
    Tracks(chrom_sizes)
    .add_point_track(
        qdf, 'p-value', x='pos', y='pval', group_by='pop',
        y_scale='log', tip_fmt='{group}: {value:.2g}',
    )
    .add_line_track(
        qdf, 'Rate (linear)', x='pos', y='rate', group_by='pop', step='post',
    )
)
viewer_log

Gaps in line and fill tracks

A missing value (NaN) breaks a line or fill track, as in matplotlib: the line or band stops at the last sample before the missing value and resumes at the next sample after it. For a fill, a NaN in y, or in either y_lo or y_hi, makes a gap. Positions that simply have no row are bridged, so add rows with NaN where the track should break. When zoomed out, a bin is only a gap if all its samples are NaN; other bins aggregate their non-missing samples.

qgap = qdf.copy()
missing = (qgap['chrom'] == 'chr1') & qgap['pos'].between(60_000_000, 120_000_000)
qgap.loc[missing, ['rate', 'ci_lo', 'ci_hi']] = np.nan

viewer_gap = (
    Tracks(chrom_sizes)
    .add_line_track(
        qgap, 'Lines', x='pos', y='rate', group_by='pop',
        step='post', tip_fmt=False,
    )
    .add_fill_track(
        qgap, 'Fill btwn', x='pos', y_hi='ci_hi', y_lo='ci_lo',
        group_by='pop', tip_fmt=False,
    )
)
viewer_gap

Hiding, showing and selecting tracks

remove_track deletes a track and its data. To take a track out of view and bring it back later without re-rendering it, use hide_track and show_track instead: a hidden track keeps its data and its place, so showing it again is instant. All three accept a track name, which selects every track with that name, or a position in the track list (negative positions count from the end).

viewer6 = (
    Tracks(chrom_sizes)
    .add_point_track(qdf, 'Scatter', x='pos', y='fst', group_by='pop', tip_fmt=False)
    .add_line_track(qdf, 'Lines', x='pos', y='rate', group_by='pop', tip_fmt=False)
    .add_fill_track(
        qdf, 'Fill btwn', x='pos', y_hi='ci_hi', y_lo='ci_lo',
        group_by='pop', tip_fmt=False,
    )
)
viewer6

added_tracks lists the names of all tracks, hidden ones included, in display order:

viewer6.added_tracks()

Hide a track and show it again:

viewer6.hide_track('Scatter')
viewer6.show_track('Scatter');

select_tracks shows only the listed tracks, in the order listed, and hides the rest. Here it shows the fill track above the line track and hides the scatter track. Passing viewer6.added_tracks() shows everything again.

viewer6.select_tracks(['Fill btwn', 'Lines']);

Tooltip

Each track contributes to the cursor tooltip unless tip_fmt=False. Use tip_fmt to control what each track contributes to the tooltip. Format placeholders use Python-style {key} or {key:.Nf} syntax.

Available keys per track type: - Gene: name, strand, start, end - Scatter / Line: group, value, x - Fill: group, lo, hi, x - Histogram: group, value, x - Segment: group - Heatmap: group, individual, nInd

If a format string references an invalid key, the tooltip shows the available keys as a hint.

viewer5 = (
    Tracks(chrom_sizes)
    .add_point_track(
        qdf, 'Scatter', x='pos', y='fst', group_by='pop',
        tip_fmt="{value:.4f} is the value for {group}",
    )
    .add_line_track(
        qdf, 'Lines', x='pos', y='rate', group_by='pop',
        tip_fmt="For {group} the value is {value:.2f}",
    )
    .add_gene_track(
        assembly='hg38', height=44, 
        tip_fmt="The gene at this pos is {name}",
    )
)
viewer5

Theme

The widget has a light and dark default theme determined by the vscodenb package if installed. You get the active theme defaults like this:

from geneinfo.widget import get_default_theme, set_default_theme
theme = get_default_theme()
theme

You can change the theme colors and save them back for use in subsequent viewers:

# theme['input_bg'] = 'pink'
set_default_theme(theme)
